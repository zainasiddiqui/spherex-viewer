# spherex-viewer
Time-lapse viewer for SPHEREx sky images: find moving and changing objects by RA/Dec.

The SPHEREx Time-Lapse Viewer lets users explore how a region of the infrared sky changes over time. Users can enter sky coordinates (right ascension and declination), search by object name, or select a preset target. The viewer displays observations of the selected region as a time-lapse, arranges individual frames in a frame grid, and offers a difference image that highlights changes between earlier and later observations. These views help users spot objects that shift against the background stars and identify candidates for follow-up. A demo mode lets users revisit previously loaded observations.
